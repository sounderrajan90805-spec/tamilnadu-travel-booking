# Tamil Nadu Travels – React Travel Booking Website

Pages: Home, Destinations (search + filter + sort), Package Details, Booking (validation + total price), My Bookings (localStorage).
Stack: React 18, React Router DOM 6, Vite, plain CSS, mock data.

## Run
npm install
npm run dev
npm run build

## Deploy
Vercel / Netlify: import the GitHub repo. Build: `npm run build`, Output: `dist`. (vercel.json and public/_redirects handle routing.)
